# حَرِّك | HARRIK — Smart School Parking & Staff Vehicle Finder

> **Find. Contact. Move.**  
> **سيارة حاجزاك؟ حَرِّك يحلها.**

نظام مواقف السيارات الذكي والتواصل الفوري مع أصحاب السيارات في المدارس (دولة قطر). يتيح للمعلم أو الموظف البحث برقم اللوحة (بالأرقام العربية أو الإنجليزية)، معرفة صاحب السيارة فورًا، والتواصل معه عبر الاتصال الهاتفي أو واتساب برابط مباشر ورسالة جاهزة، أو إرسال تنبيه موقف داخلي بحجز السيارة خلال **5 إلى 10 ثوانٍ**.

---

## المزايا الرئيسية (Core Features)

1. **بحث فوري وذكي باللوحة (Instant Plate Search):**
   - يدعم الأرقام العربية-المشرقية (`٠١٢٣٤٥٦٧٨٩`) والإنجليزية (`0123456789`).
   - تطبيع تلقائي للرموز والمسافات (`٤٨٢٧٣١` و `482731` تعطي نفس النتيجة).
   - يدعم البحث التام والبحث الجزئي بآخر أرقام اللوحة (Suffix Matching).
   - عرض فوري لبطاقة المالك، القسم، الرقم الوظيفي، والسيارة.

2. **تواصل سريع عبر واتساب والاتصال (Direct Contact):**
   - زر اتصال هاتفي مباشر (`tel:`).
   - زر واتساب برابط عميق (`wa.me`) مجهز برسالة ديناميكية عربية/إنجليزية دون الحاجة لحفظ الرقم في جهات الاتصال.

3. **دورة حياة تنبيهات المواقف (Parking Alert Lifecycle):**
   - 5 أنواع تنبيهات جاهزة (`BLOCKING`, `LIGHTS_ON`, `WINDOW_OPEN`, `CHECK_VEHICLE`, `CONTACT_ME`).
   - تنبيه مباشر لمالك السيارة مع زرين سريعين: **"جاي حالًا 🏃‍♂️"** (استلام) و **"تم تحريك السيارة ✅"** (حل).
   - احتساب دقيق لمتوسط وقت الحل وسرعة الاستجابة.

4. **لوحة تحكم إدارية وتحليلات تشغيلية (Admin Dashboard & Analytics):**
   - مبنية على بيانات Supabase حقيقية (بدون أرقام وهمية).
   - تتبع: السيارات المسجلة، نسبة التغطية، عمليات البحث اليوم، نسبة النجاح، التنبيهات النشطة، وأقدم حالة معلقة.
   - رؤى تشغيلية ذكية (وقت الذروة، سرعة الحل، تنبيه تكرار السيارات غير المسجلة).

5. **استيراد جماعي مرن (Bulk Import CSV / XLSX):**
   - فحص مسبق، كشف التكرار، ومعاينة تفصيلية (`جاهز: 126`، `تنبيهات: 3`، `أخطاء: 2`) قبل الحفظ.

6. **أمان عالي وصلاحيات صارمة (Multi-Tenant & RLS):**
   - عزل تام لكل مدرسة عبر `organization_id`.
   - صلاحيات تفصيلية (Staff, Security, Admin, Super Admin).
   - مستويات خصوصية متعددة (Mode A, Mode B, Mode C).

## متطلبات التشغيل والبدء السريع (Quick Start)

### المتطلبات الأساسية
- Node.js `v20+`
- pnpm `v10+` (أو npm)
- حساب Supabase أو بيئة محليّة (Docker + Supabase CLI)

### 1. تثبيت الحزم
```bash
pnpm install
```

### 2. إعداد المتغيرات البيئية
انسخ ملف `.env.example` إلى `.env.local`:
```bash
cp .env.example .env.local
```
وقم بملء مفاتيح مشروع Supabase الخاص بك.

### 3. تطبيق المهاجرات وقاعدة البيانات
```bash
supabase db push
# أو قم بتشغيل محتويات ملفات supabase/migrations/ في لوحة Supabase SQL Editor
```

### 4. تشغيل خادم التطوير
```bash
pnpm dev
```
افتح المتصفح على [http://localhost:3000](http://localhost:3000).

### 5. تشغيل الاختبارات
```bash
pnpm test
```

### 6. بناء حزمة الإنتاج
```bash
pnpm build
```
